# Glossaire Adrenaline System

Validé par le mainteneur le 2026-09-18. Les aperçus et l’export PNG restent tels qu’imprimés en
français ; les clés TOML (`niveauDeDanger`, `etatAlternatif`, `superficiel`…) ne changent pas.

Adrenaline System est un jeu d’origine française : ce glossaire va du terme français vers le
terme anglais choisi, à l’inverse des glossaires des autres jeux. Une note « à confirmer (VF
officielle ?) » signale un terme sans édition anglaise officielle vérifiée ; le choix retenu
n’en est pas moins celui à utiliser dans toute l’interface. Les mots d’interface génériques (Nom,
Description, Notes, Type, Min., Actuel, Max., Page, Source, Auteurs, Licence, Âge, Cheveux, Yeux,
Taille, Poids…) sont exclus : ils relèvent de la traduction ordinaire.

| LOG (Logique)                            | LOG (Logic)                             | Identique en abréviation.                                                                                                                                                                                                                     |
| VOL (Volonté)                            | WIL (Will)                              | À confirmer (VF officielle ?). | Léger                                    | Light                                   | L’éditeur affichait la clé sans accent (`leger base`) ; le dictionnaire de libellés fournit désormais « Léger » avec accent en français, et « Light base » en anglais.                                                                        |
| Grave                                    | Serious                                 |                                                                                                                                                                                                                                               |
| Profond                                  | Deep                                    | Le plus élevé des quatre seuils.                                                                                                                                                                                                              |
| Base                                     | Base                                    | Valeur du seuil sur une localisation non couverte.                                                                                                                                                                                            |
| Couvert                                  | Covered                                 | Valeur du seuil sur une localisation couverte par l’armure ou le trait de caractère.                                                                                                                                                          |
| Protection physique / Protection mentale | Physical protection / Mental protection | Le jeu traite le conflit mental comme le physique ; garder la symétrie.                                                                                                                                                                       |
| Solidité                                 | Toughness                               | Fixe le seuil superficiel.                                                                                                                                                                                                                    |
| Armure                                   | Armour                                  | Graphie britannique, retenue pour toute l’interface (voir aussi Behaviour, Licence).                                                                                                                                                          |
| Trait de caractère                       | Character trait                         | Pendant mental de l’armure.                                                                                                                                                                                                                   |
| Points (d’armure, de caractère)          | Points                                  | Le schéma parle de PP (physiques) et PM (mentaux), sigles absents de l’éditeur.                                                                                                                                                               |
| Localisations                            | Locations                               | Corporelles pour l’armure, émotionnelles pour le trait de caractère.                                                                                                                                                                          |
| Bouclier                                 | Shield                                  | Au sens mental, le schéma parle de « censure » ; « Shield » reste valable pour les deux versants.                                                                                                                                             |
| Propriétés du bouclier                   | Shield properties                       |                                                                                                                                                                                                                                               |
| Formations                               | Trainings                               | PJ et PNJ.                                                                                                                                                                                                                                    |

| Caractéristique (d’une compétence)       | Characteristic                          | Suit le choix fait pour « Caractéristiques ».                                                                                                                                                                                                 |

| Avantages                                | Perks                                   |                                                                                                                                                                                                                                               |

| Possessions                              | Possessions                             |                                                                                                                                                                                                                                               |

## PJ

| Terme du livre           | Terme anglais          | Note                                                                                                      |
| ------------------------ | ---------------------- | --------------------------------------------------------------------------------------------------------- |
| PJ                       | PC                     | Libellé du modèle dans le sélecteur de jeu ; `newTitle` dit « New player character », désormais cohérent. |
| Personnage joueur        | Player character       | Forme longue utilisée par `newTitle`.                                                                     |
| Personnage et paramètres | Character and settings | Section de l’éditeur.                                                                                     |
| Paramètres de jeu        | Game settings          |                                                                                                           |
| Joueur                   | Player                 |                                                                                                           |
| Type de création         | Creation method        | Attribution distributive ou tirage aléatoire.                                                             |
| Type de scénario         | Scenario type          | Le schéma le décrit comme le format de la partie.                                                         |
| Déclinaison de campagne  | Campaign variant       | Case proposée par le générateur officiel, absente de la feuille imprimée.                                 |
| PX                       | XP                     | Points d’expérience.                                                                                      |
| Identité                 | Identity               | PJ et PNJ.                                                                                                |
| Signes particuliers      | Distinguishing marks   | PJ et PNJ.                                                                                                |
| Adrénaline               | Adrenaline             | Aperçu seulement (pied de la fiche PJ), non traduit : l’aperçu reste tel qu’imprimé.                      |
| Panique                  | Panic                  | Aperçu seulement, non traduit.                                                                            |
| Malus                    | Penalty                | Aperçu seulement, non traduit.                                                                            |
| États                    | Conditions             | Aperçu seulement, non traduit. À ne pas confondre avec l’« État alternatif » du monstre.                  |
